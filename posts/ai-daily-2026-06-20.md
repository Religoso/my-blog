# 波士顿动力全资并入现代，AI Coding 转向 Agent 工程化

## 现代汽车 3.25 亿美元全资收购波士顿动力

现代汽车集团 6 月 19 日以 3.25 亿美元收购软银持有的波士顿动力剩余 9.65% 股份，实现对这家传奇机器人公司的 100% 控股。此前现代已于 2021 年以 11 亿美元收购 80% 股份，此役补上最后一块拼图。

波士顿动力的隐含估值在数年间从约 11 亿美元（2017 年软银收购价）飙升至约 220 亿美元，增幅约 24 倍。但软银此次以仅 3.25 亿美元退出剩余股份，实质上是一次「平价修复」——此前商业化进度未达预期，股价上行空间有限。

更值得关注的是现代汽车已明确的时间表：2028 年前在佐治亚州电动汽车工厂部署量产版 Atlas 人形机器人。这意味着 Atlas 将从 YouTube 上的「炫技视频」走向真实产线——从实验室标本到工业生产力的转型，正式开始。

现代成为继特斯拉（Optimus）、赛力斯（小赛）之后第三家将人形机器人纳入核心战略的整车企业。「自己造车，自己造造车的机器人」——这一逻辑闭环正在三家不同国家的车企中同时推进。

## NVIDIA 开源「自学插拔 GPU」全套算法

6 月 18 日，NVIDIA 具身智能实验室公布了一项令业界震动的能力展示：其训练的工业人形机器人在零人工干预下，自主完成了服务器 GPU 显卡的全流程插拔——PCIe 插槽对齐、金手指对接、卡扣锁死，全部毫米级精准操作。

但真正的战略信号不在技术本身，而在开源。NVIDIA 宣布将整套「物理世界直接泛化」训练算法、端到端模型及硬件控制接口向全球开发者完全开源。

这意味着什么？此前机器人学会一个动作需要在仿真环境（如 Omniverse）中训练数百万小时，而 NVIDIA 的新方法让机器人在面对从未见过的物理环境时，能自主适应——一个熟练工人被空降到陌生工厂，几分钟就能上手干活。这套能力的开源，等于把「机器人操作系统」级别的核心技术免费送给了全行业。

这直接对标特斯拉 Optimus 的封闭生态。黄仁勋选择做「机器人的安卓」，而非另一个「机器人的 iOS」——数百家机器人硬件厂商一夜之间获得了一套免费的高阶具身控制大脑。

## AIEC 2026：AI Coding 已不是写代码的事

6 月 17-18 日的人工智能+生态大会（AIEC 2026）上，一个判断被六位来自高校和产业界的专家不约而同地重复：AI 编程的讨论重心已经根本性地从「怎么生成代码」转向了「怎么组织工作」。

清华大学陈松将其命名为「Vibe Coding 时代」——开发者不再是代码生产者，而是问题定义者和结果审核者。TiDB 副总裁刘松的判断更加锋利：「Coding is over, Software is not。」代码生成正在被模型快速解决，但构建和交付复杂软件系统的挑战——权限、记忆、协作、安全——远未解决。他透露其公司 300 多位工程师已被禁止手写代码和人工 Review，绝大部分工作由 Agent 自主完成。

阿里云的落地方式则更加工程化：通过「Agent 专家团」模式，规划 Agent、调研 Agent、前后端 Agent、测试 Agent 各司其职，协同完成项目开发。人类研发人员「原则上尽可能少写代码」。

浪潮信息徐潇的判断回归清醒：很多开发者初次接触 AI Coding 会经历蜜月期，但很快就发现「不可靠、不可控、难复利」的问题。「四驱车装上电池就能跑，但生产级系统必须有方向盘、刹车和年检。」

本次论坛释放的核心信号：AI Coding 的终点不是写代码，而是重新定义「软件开发这项工作本身」。

## 基础设施侧：Codebase-Memory-MCP 与 LARYBench 同日亮相

6 月 20 日 GitHub 上两个项目同时登上热门榜单：

**Codebase-Memory-MCP**（DeusData）是一款将代码库转化为持久化知识图谱的 MCP 服务器，覆盖 158 种编程语言，索引毫秒级，查询亚毫秒级。核心价值在于宣称可将 AI 编程 Agent 的 Token 消耗降低 99%——通过知识图谱而非全量代码上下文来响应 LLM 查询。零依赖、单二进制交付，可直接嵌入企业级开发环境。

**LARYBench**（美团 LongCat 团队）被业界称为具身智能的「ImageNet」——一个系统性评估视觉→动作转化能力的基准框架。最反直觉的发现是：在行动泛化和控制精度上，通用视觉模型持续超越专门为机器人任务训练的具身 AI 模型。这意味着在大规模人类视频数据（如 YouTube）上训练的通用模型，意外地学会了物理操作的直觉。具身智能的「智能层」可能不需要从头研发——这是对行业研发路线图的根本性挑战。
